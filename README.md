## Overview

This repository documents the practical learning journey completed during the **AI Fluency** course.

Rather than treating the course only as a completion task, the workflow expanded into:

```text
Course
        ↓
Exercises
        ↓
Learning Artifacts
        ↓
Repository Practice
        ↓
AI Collaboration
        ↓
Applied Engineering
```

The repository preserves notes, screenshots, reflections, exercises, visual evidence, and implementation history as learning records.
